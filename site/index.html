mediatimeline macht aus einem Immich-Album eine teilbare Foto-Timeline: mit Karte aller Aufnahmeorte, Fotos und Videos nach Tagen, einer Swipe-Galerie und einer animierten Tour, die von Ort zu Ort fliegt.

▶ Live-Demo ansehen Installieren

Album in Immich

Fotos und Videos landen wie gewohnt in Immich. Beschreibungen und Kommentare werden zu Bildunterschriften.

2

Im Admin freigeben

Album auswählen, Link erzeugen, optional Passwort und Ablaufdatum setzen. Die Adminseite schützt Authelia.

3

Link teilen

Familie und Freunde sehen die Timeline im Browser – ohne Konto, ohne App, auf jedem Gerät.

Eine Timeline, die man gern durchblättert

Oben der Albumname und eine Karte mit der Route, darunter alle Fotos und Videos in zeitlicher Reihenfolge, nach Tagen gegliedert. Ein Klick auf einen Kartenpunkt springt zum Foto, ein Klick auf ein Foto öffnet die Vollbild-Galerie.

Demo-Timeline öffnen

Geführte Tour

Ein Knopf – und die Reise läuft noch einmal ab

  • Startet in der Übersicht und fliegt zum ersten Ort. Bei kurzen Wegen wird nur so weit herausgezoomt wie nötig.
  • An jedem Ort eine kurze Kartenpause mit Ortsname, dann die Fotos und Videos von dort, chronologisch.
  • Ein neuer Reisetag wird mit „Tag 2“ angekündigt.
  • Videos laufen mit Ton. Pause, vor, zurück, Wischen und Tastatur funktionieren jederzeit.
  • Wartezeit pro Foto, maximale Videolänge und Ortsradius sind pro Link einstellbar.

In fünf Minuten installiert

Ein Container-Image auf der GitHub Container Registry, eine kleine config.yaml mit Immich-URL und API-Key, fertig. Für den Dauerbetrieb liegt eine Podman-Quadlet-Unit mit Auto-Update bei, für nginx und Authelia eine Beispielkonfiguration.

Anleitung im README 
# Image holen
podman pull ghcr.io/dertika/mediatimeline:latest

# Konfiguration anlegen
mkdir -p ~/.config/mediatimeline
$EDITOR ~/.config/mediatimeline/config.yaml

# Starten
podman run -d --name mediatimeline \
  -p 127.0.0.1:8080:8080 \
  -v ~/.config/mediatimeline/config.yaml:/config/config.yaml:ro,Z \
  -v mediatimeline-data:/data:U,Z \
  ghcr.io/dertika/mediatimeline:latest
